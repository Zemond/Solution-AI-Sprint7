# Контракт, фолбэк, наблюдение, ответственность

## Ответ сервиса

Это рекомендация для очереди. Пока проверка контракта не прошла, порядок очереди не меняется.

Обязательные поля:

| Поле | Смысл |
|---|---|
| operation_id | Какая операция |
| score | Число для сортировки. Не вероятность схемы |
| band | now / today / unchanged / abstain |
| reasons | До 5 причин человеческим языком и имя признака |
| rule_flags | Какие правила уже сработали. Модель их не затирает |
| model_version | Какая версия посчитала. Пусто, если считали без модели |
| feature_time | На какой момент собраны признаки |
| completeness | ok / partial / missing |
| fallback_reason | Пусто или почему ушли на запасной путь |
| action | Всегда enqueue_only. Других значений контракт не принимает |
| snapshot_id | Ссылка на снимок признаков, чтобы человек мог открыть источник |

Поведение, если данных нет: completeness = missing, band = abstain, action всё равно enqueue_only, очередь остаётся на старом порядке «сначала крупные». Сервис не выдумывает сумму и не подставляет нули.

Проверка до любого изменения очереди:

1. Все обязательные поля на месте, score в ожидаемых границах, action только enqueue_only.
2. operation_id есть в учёте.
3. model_version из списка допущенных либо пустая, если фолбэк.
4. reasons — текст для человека, не команда и не ссылка, по которой что-то выполняется.
5. Только после этого очередь может подвинуть операцию. Приостановка клиента этим ответом не запускается.

## Фолбэк

Кейс уходит на старый порядок, а не «на средний ранг».

| Признак | Куда |
|---|---|
| Нет нужных признаков или агрегаты старше суток | abstain, старый порядок |
| Сумма, частота или контрагент далеко от того, что было на обучении | abstain, плюс метка «новый профиль» в наблюдение |
| Клиент или сегмент без истории | abstain. Новый клиент не получает «высокий риск» только из-за пустоты |
| Ранг в узкой зоне рядом с границей полосы | unchanged, не спорим из-за копеек ранга |
| Сильное правило сработало, а модель задвинула операцию вниз | Не прячем. Карточка с пометкой «расхождение», человек смотрит. Модель не побеждает правило |
| Модель или сервис признаков недоступны | Вся очередь на старый порядок за минуты, не за день |
| Отказ внешней платформы ЗСК | Не стоп. Сигнал пустой, правило и модель работают без него, в карточке видно «внешнего сигнала нет» |
| Лимиты очереди: человек не успевает | Полоса now режется до пропускной способности. Лишнее не копится «красным» бесконечно |

Общее: любой ответ, который не прошёл схему, равен недоступности модели.

## Наблюдение

Не только качество модели.

| Где | Что смотрим | Что запускает разбор или откат |
|---|---|---|
| Вход | Число операций, доля пустых признаков, доля новых контрагентов, сдвиг распределения сумм и частот | Сдвиг заметно выше обычного недели — тень, не смена боевой очереди |
| Модель | Распределение ранга, доля abstain, задержка, версия, доля расхождений с правилами | Доля abstain выросла в разы или версия не из списка — откат на старый порядок |
| Очередь человека | Возраст головы очереди, сколько разобрали, сколько контрольных разметили, не вытеснили ли крупные суммы | Контрольная выборка размечена меньше чем на 90% за неделю — ранжирование не считаем проверенным |
| Бизнес | Приостановки, снятые приостановки, жалобы, эскалации, время до разбора | Жалобы или приостановки выше сторожа из задания 4 — боевой ранг выключаем |

Повторная проверка модели — не по календарю «раз в квартал», а когда сработал сдвиг входа или просел бизнес-сторож. Откат — смена версии на предыдущую или выключение ранга. Правила при этом не откатываются: они и есть запасной путь.

## Кто за что отвечает

| Компонент | Ответственность | Не делает |
|---|---|---|
| Учёт | Хранит операцию | Не знает про модель |
| Правила | Помечают как сегодня, по внутреннему контролю | Не отменяются моделью |
| Признаки | Считают агрегаты и признаки текста | Не ходят в интернет |
| Модель | Ранг | Не блокирует, не пишет «схема» |
| Пороги | Полоса и фолбэк | Не подстраиваются сотрудником с кнопки «ослабить» |
| Очередь | Порядок показа | Не проводит платёж |
| Сотрудник | Эскалация, приостановка, метка по гайдлайну | Не обучает модель руками в обход выборки |
| Выборка | Случайные и стратифицированные кейсы в очередь | Не заменяется «ещё раз показать то, что модель любит» |
| Наблюдение | Сторожа и откат | Не чинит данные молча |
| Журнал | Кто что видел и какая версия посчитала | Не хранит лишнее сверх срока, который согласует комплаенс |
